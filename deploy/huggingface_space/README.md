# QuantDSF

QuantDSF is a Dash application for nanoDSF thermal-shift, fluorescence-quenching, dose-response, and binding-thermodynamics analysis.

This Space provides a temporary public deployment of the QuantDSF web app with curated example datasets.

The hosted app may take up to one minute to start after inactivity on the free CPU tier.
